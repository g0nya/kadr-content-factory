# Разработка

## Структура

| Путь | Назначение |
| --- | --- |
| `public/` | Интерфейс, перечень провайдеров по задачам и демонстрационные материалы |
| `server.mjs` | Локальный HTTP-сервер, управление обработкой и экспорт FFmpeg |
| `provider-api.mjs` | Вызовы провайдеров для анализа, расшифровки, перевода и генерации речи |
| `voice-render.mjs` | Подгонка синтезированного аудио к таймкодам клипа |
| `test/` | Проверка экспорта MP4 с тестовыми ответами API |

Сервер слушает `127.0.0.1:4173` и обрабатывает один проект за раз. Порт можно изменить переменной `PORT`. Переменные `FFMPEG` и `FFPROBE` позволяют указать другие исполняемые файлы.

## Как обрабатывается видео

1. Сервер сохраняет исходник в `data/<id>/`. FFmpeg извлекает аудио, провайдер распознавания возвращает текст и интервалы реплик.
2. Модель анализа выбирает непересекающиеся фрагменты по расшифровке. Дополнительные модели могут перевести реплики, подготовить текст для публикации и озвучить их.
3. FFmpeg собирает клипы и обложки. Если доступен фильтр `subtitles`, субтитры вшиваются в кадр. Иначе MP4 получает переключаемую текстовую дорожку, а плеер использует WebVTT. При переводе исходные субтитры доступны отдельным SRT.
4. Метаданные и файлы экспорта сохраняются рядом с исходником. Провайдеры и ключи не записываются в метаданные проектов.

## Проверки

```sh
npm run check
npm test
```

Интеграционный тест использует демонстрационный MP4 и локальные ответы вместо платных запросов. Он проверяет переключение провайдеров озвучки, перевод, экспорт звука и сохранение клипа при ошибке API. Для запуска требуется FFmpeg с `libmp3lame`.

## Типовые ошибки

- Если локальный адрес не открывается, проверьте, что сервер запущен и порт свободен.
- Если API возвращает 401 или 403, проверьте ключ и доступ к указанной модели.
- Если готовый клип сохранился без дополнительного результата, причина появится рядом с проектом в разделе «Проекты».
